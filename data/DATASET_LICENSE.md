# Dataset provenance and reuse notice

The file `online_shoppers_intention.csv` contains the **Online Shoppers Purchasing Intention Dataset**, created by **C. Sakar and Yomi Kastro** and originally distributed by the **UCI Machine Learning Repository**.

- Original dataset: https://archive.ics.uci.edu/dataset/468/online+shoppers+purchasing+intention+dataset
- DOI: https://doi.org/10.24432/C5F88Q
- Reference: Sakar, C., & Kastro, Y. (2018). *Online Shoppers Purchasing Intention Dataset* [Data set]. UCI Machine Learning Repository.
- Dataset license: **Creative Commons Attribution 4.0 International (CC BY 4.0)**, https://creativecommons.org/licenses/by/4.0/
- Provenance: The submission copy was retrieved from a publicly available dataset mirror and verified against the author's executed UCI analysis: **12,330 rows, 18 columns, 1,908 positive outcomes, no empty cells**, plus the published ProductRelated_Duration and PageValues means/maxima. The original UCI repository is the authoritative source.

The dataset is a third-party research asset, **not** original data collected by this project author. Inclusion in the university submission is permitted under CC BY 4.0 subject to attribution.
